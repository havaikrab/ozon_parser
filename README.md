# ozon_parser

## Описание
ozon_parser - инструмент для извлечения сведений о продуктах, размещенных на сайте ozon.ru.  

## Запуск
Клонируйте проект на собственный ПК. Установите зависимости и активируйте виртуальное окружение.  
Создайте env-файл и разместите в нем личные данные в соответствии с шаблоном .env_template.  
Для работы ozon_parser вам необходимо иметь google-аккаунт.  
Также с помощью google-cloud необходимо получить разрешения для автономного подключения
ozon_parser к вашему почтовому ящику. Следуйте инструкциям от google-cloud.  
В начале модулей get_cookies.py и parse_ozon.py указаны несколько переменных-констант,
с помощью них можно настроить оптимальное поведение программы. Переменные имеют соответствующие комментарии.  
ВАЖНО! Переменная CREDENTIALS_FILE ссылается на файл с вашими разрешениями от google-cloud,
файл с разрешениями должен быть заполнен до первого запуска программы.  
При первом запуске google также попросит подтвердить разрешение на подключение программы к вашей почте.  

## Порядок работы
В переменную SKU_LIST в parse_ozon.py необходимо передать список строк с артикулами продуктов и запустить  
исполнение данного модуля. 
При наличии актуальных заголовков и куки-файлов ozon_parser сразу начнет отправлять запросы к
внутреннему api ozon.ru. После истечения сессии или при первом запуске программа сначала
обновит куки и заголовки, а затем продолжит извлечение данных. Полученная информация будет сохранена в csv-файл.
